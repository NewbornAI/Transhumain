# Transhumains

*Univers de science-fiction et de transhumanisme : lore, règles de jeu de rôle, direction artistique et l'application qui les sert.*

## Ce qu'il y a ici

| chemin | contenu |
|---|---|
| `00 Accueil/` | le point d'entrée et le MOC |
| `Lore/`, `Regles/`, `Equipement/`, `Vaisseaux/`, `Personnages/`, `Campagne/`, `Fiction/` | l'univers et ses règles |
| `Source/` | les documents Office d'origine (xlsx, docx, drawio) dont les notes sont issues |
| `App/` | l'application de bureau, construite depuis le PRD (phases 0 à 50) |
| `MEDIA.md` | où sont les images, et comment les remettre |

## Les images ne sont pas dans git

Environ 272 Mo de PNG vivent hors du dépôt, pour que le clone reste du texte. Voir [MEDIA.md](MEDIA.md) : l'archive, la raison, et la restauration en deux commandes.
