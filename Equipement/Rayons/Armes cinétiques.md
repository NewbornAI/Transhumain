## Tir rapide (règles)

Règle de résolution (conservée ici faute de section Combat dans les [[Transhumains - Règles|Règles]] — à migrer) :

1. Visée & cadence (si applicable). Jet, retirer l'esquive. hits = 0 → toutes les touches sont sur cible ; hits < 0 → 1 tir raté ; hits > 0 → le reste = visée.
2. Un dé de localisation par projectile (feuille de perso, [[Transhumains - Règles#Création|FP]]). L'autopilote tire sur la localisation la plus proche non couverte ; viser une localisation coûte 1 hit par pas de dé ; viser un point faible (main, œil) donne un effet de statut ou +1 dégât ; viser une faiblesse d'armure réduit une couche de 1.
3. Par couche (couverture > externe > dermique > interne, [[Armures#Annexe — couches d'armure|Armures]]) : AP > armure → traverse ; AP = armure kinétique → traverse mais −1 AP ; sinon dégâts. Dégâts < armure → éclaboussure, le tir suivant sur la même localisation +1 dégâts ; = → l'armure casse sans blessure ; > → détruit l'armure, le reste traverse.
