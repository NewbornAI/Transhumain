# Chimie & effets

> [!info] Rayon
> Substances à composer : un **composé** de base + des **modificateurs**. Prix du composé = **P ₡** (✅ tranché par le MJ — [[00 Sommaire des rayons#Notations surfaced ⚠️ — à trancher, non devinées|N5]]). `P` = **puissance visée**, indice 1–6 (N4 — ✅ tranché). Synthèse maison : 10 doses pour 1 capsule de biogel ([[Transhumains - Règles#Crafting|Crafting]]).
>
> **Catalogue HTML** : une seule carte **« ⚗ CONFIG »** pour le composé — puissance P (1–6), add-ons cochables avec prix recalculé en direct, nombre de doses. Les add-ons ne sont plus des articles séparés ; leur prix suit la table ci-dessous.

## Bases

| Base | Prix | Permis | Description |
|---|---|---|---|
| Composé (100 doses) | P ₡ | — | Biologie. Couteau-suisse chimique. Base = puissance visée (1–6 ₡), sur laquelle se greffent les modificateurs. |
| Malware | P × base | `M` | Électronique. P = compétence visée ([[Électronique#Matrice\|virus éveillé]] en version matricielle). |
| Nanobots | base + 1 ₡ | — | Ingénierie / Biologie / Électronique. |

### Exemple de composition chiffrée

Toxine P4, effet rapide, contagieuse : base P (4 ₡) + toxine +P (4 ₡) + rapide (+2 ₡) → 10 ₡, ×2 contagieux = **20 ₡ / 100 doses**, permis `I` requis. *(illustration des conventions N4/N5 tranchées)*
